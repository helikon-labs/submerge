A free online REST API that you can use whenever you need some fake data.
JSONPlaceholder comes with a set of 6 common resources:
- Posts
- Comments  
- Albums
- Photos
- Todos
- Users

This is a fully functional API - all endpoints are live and working!
You can test them immediately at https://jsonplaceholder.typicode.com
